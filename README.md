# Fast Tavel : app desktop de gestion d'avion

Ceci est application desktop développée en C# permettant de gérer les informations liées aux avions. Le projet a été réalisé dans 
le cadre de notre formation afin de mettre en pratique la programmation orientée objet et la conception d'une application de 
gestion.

##Fonctionnalités :
- Ajouter, modifier et supprimer un avion
- Consulter la liste des avions
- Rechercher un avion
- Gérer les informations des avions
- Gestion des vols
- 
##Téchnologies utilisées :
- C#
- Avalonia
- POstgreSQl
- FXMl
